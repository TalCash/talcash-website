How it works

Mining that doesn't reward special hardware

Every hash is an Argon2id calculation that needs 4 MiB of fast memory. That makes custom mining chips pointless and keeps graphics cards' edge small, so the computer you already own can mine. Difficulty adjusts a little after every block to keep one block a minute.

A reward that stays the same

10 TC for every block, with no halvings and no end date: about 5.26 million TC a year. That amount never changes, so as a share of all coins it gets smaller every year. The first block pays an address nobody can spend, so nobody starts with coins.

Payments nobody can alter

One payment can pay up to 255 addresses at once. Its signature covers every address, amount and note, so changing any detail makes it invalid. Fees start at 0.000146 TC for a simple payment, and miners choose which payments to include.

History you can copy

Each day of blocks is sealed into a single file, and every block carries a fingerprint of all balances at the end of the previous day. New nodes download whole days and check every block in them. After 100 blocks, about 100 minutes, a payment can't be undone.

Try it on your computer

Mainnet isn't live yet, but devnet is: the same rules at 60× speed, one block a second, running only on your machine. You need Python 3.11 or newer.

  1. Get the code

    git clone https://github.com/TalCash/TalCash
cd TalCash
pip install -e .

  2. Create a wallet

    tc --network devnet wallet create

    Write down the 24 words it shows you. They are the only way to recover the wallet.

  3. Start mining

    tc --network devnet node --mine

  4. Check your balance in a second terminal

    tc --network devnet wallet balance

    Mined coins unlock after 100 blocks, under two minutes on devnet.
